# Customer Churn Prediction & Retention Analysis

An academic data science project exploring **which telecom customers might leave**, how to group customers by churn risk, and how these insights could support customer retention conversations.

## Why I worked on this

I wanted to understand how customer behaviour can be analyzed to help businesses identify potential retention challenges and make more informed decisions.

## What the notebook covers

- Data preparation and handling missing values
- Logistic Regression and CatBoost classification models
- Comparing model predictions using ROC-AUC and classification reports
- High / medium / low customer risk segments based on predicted churn probability
- Simple illustrative lifetime value and value-at-risk estimates
- SHAP explanations to explore model features
- Suggested retention actions for different risk groups

## Results recorded in the original notebook

| Model | ROC-AUC | Accuracy |
|---|---:|---:|
| Logistic Regression | 0.8418 | 80.7% |
| CatBoost | 0.8456 | 80.6% |

Results are from a held-out test split recorded in the submitted notebook, **not** a new independently verified run. These figures are estimates of predictive performance on the supplied dataset, not measures of actual customer retention improvements.

## Business takeaway

Customer churn analysis can help teams prioritize which customers may need an earlier conversation or service review. A prediction is not a confirmed explanation of why an individual customer leaves, and outreach strategies in this project were proposed rather than deployed or tested.

## How to run

1. Download the IBM Telco Customer Churn example dataset from its original source (search for **IBM Telco Customer Churn dataset**).
2. Save the file at `data/Telco-Customer-Churn.csv` (the dataset has columns including `customerID`, `tenure`, `Contract`, `MonthlyCharges`, and `Churn`).
3. From the project root, install packages with `pip install -r requirements.txt`.
4. Open `notebooks/customer_churn_analysis.ipynb` in Jupyter and run the cells in order.

**Note:** The notebook was adapted to use the repository's relative dataset path. It includes exploratory iterations and has not been independently rerun end-to-end in this package. Its output charts are regenerated by executing the code. Exported customer-level tables are intentionally excluded from this public portfolio package.

## Limitations

- The dataset is a public educational telecom example, not real clients of Recruit CRM.
- The CLV illustration uses an **assumed 30% profit margin and 12 months**; it is not an audited financial forecast.
- Risk thresholds (0.30 / 0.70) and retention actions are illustrative.
- The project does not demonstrate a production-deployed model or actual retention uplift.

## Tools

Python, Jupyter Notebook, pandas, NumPy, scikit-learn, CatBoost, SHAP and Matplotlib.
